
# Front-Ice

![Front-Ice Logo](https://firebasestorage.googleapis.com/v0/b/front-15551.appspot.com/o/Logo%2FLogo%20high-res%20transparent.png?alt=media&token=53a7ce5f-3a9d-4c8a-a1f0-cb5b2006ba85)

> 🚀 A platform providing programming challenges and recruitment support for FrontEnd developers.

## 📌 Overview
The **Front-Ice Project** is a platform designed to help FrontEnd developers improve their skills and advance their careers. Developers who join the platform will have access to numerous job postings directly from employers, optimizing their personal growth and job search process.

## ✨ Features
- 🏆 **Create coding challenges** for users to practice
- 🔗 **Build community connections** among developers
- 📊 **Assess technical skills** through tests
- 💼 **Provide job opportunities** for developers
- 🏢 **Help companies** find high-quality candidates
- 🎨 **Modern UI/UX** with an intuitive design
- 🖌️ **Provide modern Figma design files** for better UI development

## 🏗️ Tech Stack
- **Frontend Framework:** ReactJS
- **Backend Framework:** Spring Framework
- **State Management:** Redux / Pinia
- **UI Library:** Tailwind CSS / Ant Design
- **Build Tool:** Vite / Webpack
- **Testing:** API Dog / JUnit
- **CI/CD:** Railway

## 🚀 Getting Started

### 1️⃣ Prerequisites
Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (LTS version recommended)
- [Java](https://www.oracle.com/java/) (JDK 11+)
- [Yarn](https://yarnpkg.com/) or [npm](https://www.npmjs.com/)

### 2️⃣ Installation
```sh
# Clone the repository
git clone https://github.com/your-repo/front-ice.git
cd front-ice

# Install dependencies (Frontend)
yarn install  # or npm install

# Install dependencies (Backend)
cd backend
./mvnw install  # or mvn install
```

### 3️⃣ Running the App
```sh
# Start the frontend server
yarn dev  # or npm run dev

# Start the backend server
cd backend
./mvnw spring-boot:run  # or mvn spring-boot:run
```

### 4️⃣ Building for Production
```sh
# Frontend build
yarn build  # or npm run build

# Backend build
./mvnw package  # or mvn package
```

## 🚀 Deployment
- **Vercel:** `vercel --prod`
- **Netlify:** `netlify deploy`
- **Docker:**
```sh
docker build -t front-ice .
docker run -p 3000:3000 front-ice
```
